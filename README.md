# ReAct Agent 演示器

## 项目简介
本项目是一个基于 **ReAct (Reasoning + Acting)** 范式的智能体（Agent）演示系统。它通过结合大语言模型（LLM）的推理能力与外部工具的执行能力，能够自主完成复杂的逻辑计算、信息查询和文件操作任务。

项目包含一个功能完整的命令行版本和一个交互友好的 Web 可视化界面，旨在直观地展示 AI Agent “思考-行动-观察”的完整工作流。

---

## 核心功能
- **ReAct 推理引擎**：实时展示 Agent 的思考过程（Thought）、工具调用（Action）及执行结果（Observation）。
- **多工具协同**：内置多种实用工具，包括：
  - **数学计算器**：支持复杂表达式及多行批量计算。
  - **实时天气查询**：集成 wttr.in API，获取全球城市天气。
  - **沙箱文件系统**：安全的文件读写（覆盖/追加）与内容检索。
  - **时间获取**：实时获取系统时间与日期。
- **双模式运行**：
  - **Web 界面**：支持流式输出（Stream），动态呈现推理步骤，交互体验极佳。
  - **命令行 (CLI)**：适合快速测试与脚本化调用。
- **环境隔离**：所有文件操作均在 `agent_workspace` 沙箱中进行，确保系统安全。

---

## 技术栈
- **后端框架**：Python, Flask
- **AI 模型**：阿里云通义千问 (Qwen3.5-plus) via DashScope API
- **前端技术**：HTML5, CSS3, JavaScript (原生实现，无第三方依赖)
- **其他库**：`openai`, `requests`, `math`

## 快速开始

### 1. 环境准备
确保你的电脑已安装 Python 3.8 或更高版本。

### 2. 安装依赖
在项目根目录下打开终端，运行以下命令：
```bash
pip install -r requirements.txt
```

### 3. 配置 API 密钥
本项目使用阿里云 DashScope API。请设置环境变量 `DASHSCOPE_API_KEY`：

**Windows (PowerShell):**
```powershell
$env:DASHSCOPE_API_KEY="sk-your-api-key-here"
```

**Windows (CMD):**
```cmd
set DASHSCOPE_API_KEY=sk-your-api-key-here
```

*(建议将密钥永久添加到系统环境变量中，以便每次启动时无需重复设置)*

### 4. 运行项目

#### 方式 A：启动 Web 演示界面（推荐）
```bash
python app.py
```
启动后，在浏览器访问 `http://127.0.0.1:5000` 即可体验流式推理过程。

#### 方式 B：命令行测试
```bash
python door.py --message "帮我计算一下 (85+90)/2 的结果并写入文件"
```

## 目录结构说明

| 文件/目录 | 说明 |
| :--- | :--- |
| `app.py` | Flask Web 服务器主程序，负责处理前端请求与流式输出 |
| `door.py` | Agent 核心逻辑实现，包含 ReAct 循环与所有工具定义 |
| `templates/` | 存放 Web 页面的 HTML 模板 |
| `static/` | 存放前端的 CSS 样式与 JavaScript 脚本 |
| `agent_workspace/` | **沙箱目录**：Agent 执行文件读写操作的工作区 |
| `requirements.txt` | Python 依赖清单 |
| `ENV_SETUP.md` | 详细的环境变量配置指南 |

## 演示示例
作者提供的初始演示包

其中应该含有weather_comparison.txt，记录了杭州与北京的气温情况，你可以：


问：

```text
查看与天气相关的文档，统计里面的记录数，检查是否有近1h内的记录，如果没有，就追加一条记录
```

常规情况，AI能够完成记录追加。
接下来对其中的一个数值更改，如把北京30改为22，手动制造错误，接下来：

问：

```text
查看与天气相关的文档，统计里面的记录数，检查是否有近1h内的记录，如果没有，就追加一条记录，如果有，就检查它是否准确，不准确就更新它，把做出的修改写成报告保存
```

那么AI将能够查询结果，并更新记录，保存更新报告
